# Kritin Rane — Portfolio

A minimalist, scroll-based personal portfolio built with Next.js, Tailwind CSS,
and Framer Motion. The hero section features a 3D ID card that reacts to the
cursor — as the pointer approaches, the card tilts and glides away in the
opposite direction.

## Stack

- [Next.js](https://nextjs.org/) (App Router)
- [Tailwind CSS v4](https://tailwindcss.com/)
- [Framer Motion](https://www.framer.com/motion/)

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content

Profile content (name, experience, skills, links) lives in `lib/data.ts`.

## Deploy

Deploy directly to [Vercel](https://vercel.com/new) — no configuration
needed.
